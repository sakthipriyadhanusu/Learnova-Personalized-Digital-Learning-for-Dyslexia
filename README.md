# 🚀Learnova-Personalized-Digital-Learning-for-Dyslexia

Learnova is a smart app based platform designed to assist students, parents, and educators by providing an AI-assisted screening and recommendation system. It helps identify early signs using cognitive tests, provides tailored recommendations, and maintains reports for continuous monitoring.

---

## 🧠 Key Features

### ✅ 1. AI-Based Screening  
- Interactive tests  
- Automated scoring  
- Real-time evaluation  

### ✅ 2. Intelligent Recommendation System  
- Personalized suggestions based on results  
- Activities, exercises, and learning strategies  

### ✅ 3. User Roles  
- **Student** – Takes screening tests  
- **Parent** – Views progress and reports  
- **Teacher** – Monitors students  
- **Admin** – Manages users & system  

### ✅ 4. Progress Tracking  
- Line graphs  
- Weekly and monthly insights  
- Downloadable reports

## 📈 Results

The **Personalized Digital Learning for Dyslexia** system was tested using sample academic documents, scanned notes, and textbook images. The results show that the system effectively improves content accessibility and readability for dyslexic learners.

### Key Results

- ✔ Accurate text extraction from images and documents using OCR
- ✔ Simplified explanations generated for complex educational content
- ✔ Automatic summarization of learning materials
- ✔ Reduced reading complexity and improved content clarity
- ✔ Creation of personalized digital notes for future reference

### Performance Summary

| Metric | Result |
|------|--------|
| OCR Accuracy | High for clear printed documents |
| Text Simplification | Effective reduction in sentence complexity |
| Summarization Quality | Clear and concise |
| User Accessibility | Dyslexia-friendly output |
| Learning Efficiency | Reduced reading time |
